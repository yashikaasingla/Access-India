# 🇮🇳 Accessible India

**Accessible India** is a web-based project developed during a **48-hour hackathon** to make digital experiences more accessible and inclusive.

## ✨ Features

* 🎤 Voice interaction
* 🔊 Text-to-speech
* 🧭 Simple navigation
* 📱 Responsive design
* ♿ Accessibility-focused interface

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

## 🎯 Goal

To reduce digital barriers and create a simple, inclusive, and user-friendly experience for everyone.

**Made with ❤️ for Accessible India 🇮🇳**
